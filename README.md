# BookVerse Final Project

BookVerse is a responsive book discovery website for students and curious readers.

**Team:** Hour

**Members:** Khairgeldi Bekzat, Talapek Meyirzhan

**Group:** SE-2503 — Astana IT University

## Pages

- **Home:** project introduction, featured books, personalized greeting, and subscription demo.
- **Catalog:** nine books, title/author search, category filters, ratings, details, and reading list.
- **About Us:** project goal, team information, and FAQ.
- **Contact:** three-step book suggestion form with custom validation.
- **Reader Account:** local demo sign-up, log-in, and profile.
- **Discover:** live Google Books search with an Open Library fallback if Google Books is rate-limited.

## Main features

- Responsive Bootstrap layout and a light/dark theme saved across pages.
- JavaScript form validation for names, email, phone number, and password.
- Local demo authentication and profile data stored in browser `localStorage`.
- Dynamic catalog search, category filtering, ratings, and saved reading list.
- jQuery autocomplete, notifications, scroll progress, and UI effects.
- Public book API integration with loading and error feedback.

Account credentials are stored only in the current browser to demonstrate the assignment requirement. Use sample data only; this is not a secure production login. Contact-form submissions are not sent to a server.

## Run locally

Open `index.html` or serve the folder with a static HTTP server. An internet connection is needed for jQuery and live book search.
