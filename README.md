# BookVerse

BookVerse is a responsive and interactive student website for discovering classic literature, science fiction, fantasy, and educational books.

**Live website:** https://wrnrkbrg5w-alt.github.io/midka/

## Pages

- **Home** — introduction and popular books
- **Catalog** — featured carousel and complete book collection
- **About Us** — project mission and team information
- **Contact** — JavaScript form validation demo

## Technologies

- HTML5
- CSS3 and media queries
- Bootstrap 5
- Flexbox and Bootstrap Grid
- JavaScript DOM events and validation

## Assignment 4 Features

- Custom form validation with clear errors for required fields, email format, password length, and password confirmation
- FAQ accordion with smooth open and close transitions
- Responsive popup subscription form
- Background color changer
- Dynamically updated current date and time

## JavaScript Files

- `js/main.js` - background color changer and live date/time (Khairgeldi Bekzat)
- `js/components.js` - FAQ accordion and popup form (Talapek Meyirzhan)
- `js/validation.js` - collaborative custom form validation

## Responsiveness

The website adapts to desktop, tablet, and mobile screens. Bootstrap Grid controls the main layouts, while custom media queries adjust typography, cards, navigation, and buttons.
