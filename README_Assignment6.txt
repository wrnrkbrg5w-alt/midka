PROJECT CONTENTS
- index.html, catalog.html, about.html, contact.html, discover.html, account.html: six connected site pages
- css/style.css: shared styling, themes, and Assignment 6 visual components
- js/main.js: shared theme, greeting, audio, date/time, and navigation behavior
- js/catalog.js: book data, filtering, ratings, and reading-list behavior
- js/components.js: FAQ and subscription popup behavior
- js/validation.js: three-step contact form validation for full name, email, phone, and message
- js/account.js: localStorage sign-up, log-in, and reader profile simulation
- js/discover.js: live Google Books API search with an Open Library fallback
- js/script.js: Assignment 6 jQuery features (Tasks 0-9)
- vendor/: local Bootstrap files and license
- img/: local book-cover illustrations
- audio/: local notification sound

ASSIGNMENT 6 FEATURES
1. Real-time catalog search and live filtering
2. Autocomplete book suggestions
3. Search-term highlighting in matching book titles and authors
4. Gradient scroll-progress bar
5. Animated project-stat counters (9 books, 6 pages, 2 team members)
6. Submit-button loading spinner and disabled state during a simulated local request
7. Temporary fading toast notifications
8. Copy-to-clipboard project URL button with checkmark feedback
9. jQuery scroll-based lazy loading for local book-cover images

RUNNING THE PROJECT
Open index.html in a modern browser. The project uses local Bootstrap assets and the official jQuery 4.0.0 CDN specified in the assignment. An internet connection is required for the CDN script to load. The forms are local demonstrations; no profile or subscription data is sent to a server. Reader accounts are stored in browser localStorage for the required authentication simulation. Use sample credentials only; never enter a real password. The Discover page requires an internet connection and loads live results from Google Books and falls back to Open Library if Google Books rate-limits the request.
