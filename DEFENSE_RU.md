# Подготовка к защите Assignment 5

Проект продолжает BookVerse из Assignment 4. Команда Hour, группа SE-2503.

## Порядок демонстрации

1. На Home введи имя и нажми Update greeting. `getElementById` находит заголовок, `textContent` меняет текст. Пользовательский ввод не передаётся в `innerHTML`.
2. Нажми Night mode. `applyTheme` меняет атрибут `data-bs-theme`, CSS задаёт цвета. Выбор сохраняется в localStorage и применяется на остальных страницах.
3. В верхнем меню используй стрелки, Home и End. `keydown` передаёт событие, `switch(event.key)` выбирает действие, `focus()` переводит фокус. Индекс вычисляется по кругу через остаток от деления.
4. Открой Catalog. Выбери Science fiction и введи Dune. `filter` применяет категорию, поиск и режим списка чтения одновременно. `map(createBookCard)` создаёт карточки результата.
5. Нажми Read more. `style.display` показывает описание, `aria-expanded` сообщает состояние вспомогательным технологиям.
6. Поставь 4 звезды. Цикл `for` создал пять кнопок, `querySelectorAll` находит их, `forEach` добавляет `selected` до выбранной оценки. `library.setRating` сохраняет оценку.
7. Добавь книгу в список чтения, включи My reading list и перезагрузи страницу. `Set` исключает повторные ID, для localStorage он превращается в массив. При удалении последней книги появляется пустое состояние.
8. При добавлении книги CSS запускает `saved-pulse`, JavaScript воспроизводит WAV. Один объект `Audio`, `pause()` и сброс `currentTime` предотвращают наложение. Sound: off выключает автоматические сигналы, Play sound явно воспроизводит пробный звук.
9. В Contact нажми Next с пустыми полями. Покажи ошибки. Введи тестовые данные, перейди на второй шаг и вернись назад. Значения сохраняются, потому что поля остаются в DOM, меняется только `hidden` у fieldset.
10. Дойди до Review, подтверди согласие и нажми Finish profile. Пароль не выводится в обзор. Данные формы не отправляются и не сохраняются. Reset очищает поля и возвращает первый шаг.

## Основные понятия

- Объект хранит связанные свойства и методы. `library` содержит оценки, список и методы изменения.
- Массив `books` хранит девять объектов книг. `for` создаёт звёзды; `forEach` обрабатывает элементы.
- Функция высшего порядка принимает другую функцию. `navigateStep(1, showStep)` получает callback и вызывает его с номером шага.
- Делегирование событий: один обработчик на `#book-grid` ищет ближайшую кнопку через `closest`. Поэтому кнопки работают и после повторного создания карточек.
- `preventDefault()` отменяет стандартное действие: форму не отправляет браузер, стрелки не прокручивают страницу при навигации меню.
- `localStorage` хранит строки; `JSON.stringify` сериализует значения, `JSON.parse` восстанавливает. `try/catch` обрабатывает недоступное хранилище и некорректный JSON.
- Разделение HTML/CSS/JS упрощает изменения: разметка описывает структуру, CSS внешний вид, JS поведение.

## Что можно изменить на защите

- Добавить книгу в `books`, положить её обложку в `img` и заменить текст о количестве книг.
- Добавить категорию в select, `categoryNames` и `describeCategory`.
- Изменить минимальную длину пароля в `validationFields.userPassword.validate` и пояснении HTML.
- Поменять длительность `.just-saved` или цвета ночной темы в CSS.
- Изменить формат даты в `updateDateTime`.

## Решённые сложности

После фильтрации карточки создаются заново: делегирование событий сохраняет работоспособность кнопок. В режиме My reading list удаление последней книги переводит фокус на фильтр и показывает подсказку. Быстрое переключение FAQ раньше могло скрыть уже открытую панель: таймер закрытия отменяется при новом нажатии. `prefers-reduced-motion` отключает анимации по системной настройке пользователя.
